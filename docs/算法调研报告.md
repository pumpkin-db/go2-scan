# 前沿算法调研报告：四足机器人自主探索与智能导航

> 调研时间：2026-07-29
> 目标场景：Unitree Go2 + MID360 + 前置相机，未知环境赋色点云采集，10分钟限时
> 硬件约束：NVIDIA Orin NX 16GB (~100 TOPS INT8)

---

## 全景总结

当前机器人自主探索领域正经历从**经典信息论方法**向**学习型/基础模型引导方法**的范式转变。2024-2026年的关键趋势：

1. **NBV/探索规划**仍是核心问题，但评分函数从纯信息增益演变为"信息增益 + 重建质量 + 行进代价"的多目标优化
2. **RL 探索策略**已从仿真走向实机（MA-SLAM 2025、Jonnarth 2024 均有真机验证）
3. **VLM/LLM 引导探索**是最新热点（Berkeley 2025 将 VLM 推理集成到前沿选择中）
4. **VLA 边缘部署**已成为现实——LiteVLA-Edge 在 Jetson Orin NX 上实现 6.6Hz 控制
5. **Go2 专用方案**已有多篇论文和开源项目（Becoy 2025 的覆盖路径规划、exploration_go2）

**对你的比赛最相关的发现：** Becoy 2025 的论文几乎就是你的比赛场景——Go2 EDU + ROS2 + 覆盖路径规划。这是最直接的参考。

## Tier 1: 自主探索 / NBV（深入）

### 领域现状

NBV（Next-Best-View）问题已有30年历史，核心是"给定当前地图状态，选择下一个最优观测位置"。经典方法基于信息论（互信息、熵减少），近年来向三个方向分化：(1) 考虑重建质量的 NBV，(2) 学习型探索策略（RL/IL），(3) 语义/基础模型引导的探索。

### 候选算法清单

| 算法/系统 | 年份 | 核心思想 | 比赛适配性 | 硬件需求 | 开源 | 备注 |
|-----------|------|---------|-----------|---------|------|------|

### 对本项目的启示

**可直接借鉴的（2个月内可落地）：**
- Station-Viewpoint Joint CPP 的"站点+视点联合规划"思想——你的问题本质就是"去哪些站点，以什么朝向观测"
- PB-NBV 的投影法可见性计算——高效判断"从这个位置相机能看到哪些体素"
- frontier_exploration_ros2 作为工程起点
- Asymptotically-Bounded 3D Frontier 的 OctoMap 熵变信息增益

**长期有价值的：**
- MA-SLAM / MapExRL 的 RL 探索策略——训练一次，泛化到不同环境
- VLM-Guided Frontier——语义理解引导"哪里值得去"

**不适合当前约束的：**
- Active Neural SLAM 原版——需要大量GPU训练+Habitat仿真环境
- VLM引导——Orin NX 跑 VLM 推理延迟太高，不适合实时探索决策

## Tier 2: VLA / 世界模型 / 自动驾驶规划（重点）

### VLA（Vision-Language-Action）

| 算法/系统 | 年份 | 核心思想 | 比赛适配性 | Orin NX可行性 | 开源 |
|-----------|------|---------|-----------|-------------|------|
| **LiteVLA-Edge** | 2026 | 量化VLA，Jetson Orin原生部署 | ⭐⭐⭐ 长期 | ✅ **6.6Hz @ Orin NX** | [arXiv](https://arxiv.org/html/2603.03380v1) |
| **TinyVLA** | 2025 | 紧凑VLA家族，快速数据高效 | ⭐⭐⭐ 长期 | ✅ 设计目标即边缘 | [Project](https://tiny-vla.github.io/) |
| **LiteVLA** (CPU版) | 2025 | 纯CPU推理的VLA | ⭐⭐ 备选 | ✅ CPU即可 | [arXiv](https://arxiv.org/html/2511.05642v1) |
| **OpenVLA** | 2024 | 7B开源VLA | ⭐ 太大 | ❌ 需>16GB | [GitHub](https://github.com/jonyzhang2023/awesome-embodied-vla-va-vln) |
| **π0 (pi-zero)** | 2024 | Flow-matching VLA | ⭐⭐ 研究 | ❌ 太大 | 部分开源 |
| **CogAct** (MulticoreWare) | 2025 | 优化部署的VLA | ⭐⭐⭐ | ✅ 已验证边缘 | [Blog](https://multicorewareinc.com/deploying-vision-language-action-vla-based-ai-models-in-robotics-optimization-for-real-time-edge-inference/) |

**关键发现：LiteVLA-Edge 在 Jetson Orin NX 上实现 150ms 延迟（6.6Hz）。** 这意味着 VLA 在你的硬件上是可行的，但频率有限——适合做高层决策（1-5Hz），不适合做底层运动控制（需要50Hz+）。

### 世界模型

| 算法/系统 | 年份 | 核心思想 | 比赛适配性 | 备注 |
|-----------|------|---------|-----------|------|
| **V-JEPA 2** (Meta) | 2025 | 视频训练的世界模型，零样本规划 | ⭐⭐ 研究方向 | [Meta Blog](https://ai.meta.com/blog/v-jepa-2-world-model-benchmarks/) |
| **World Action Models** (NVIDIA) | 2026 | 动作条件世界模型(DreamDojo/Genie/JEPA-WM) | ⭐⭐ 前沿 | [NVIDIA Blog](https://developer.nvidia.com/blog/pretrained-to-imagine-fine-tuned-to-act-the-rise-of-world-action-models/) |
| **Hierarchical World Models for TAMP** | 2025 | 分层世界模型引导任务运动规划 | ⭐⭐⭐ 思路 | [OpenReview](https://openreview.net/pdf?id=OQ7cB8ChvF) |
| **Dreamer v3** | 2023 | 通用RL世界模型 | ⭐⭐ 基础 | 经典但需GPU |

**世界模型对你场景的潜在价值：** "预测如果机器人走到位置X、面朝方向Y，相机能看到多少新表面"——这本质是一个轻量世界模型。但不需要完整的视频预测世界模型，一个**几何投影模型**（给定pose→预测可见体素）就够了。这就是 NBV 中的 ray-casting 可见性计算。

### 自动驾驶规划（迁移价值）

| 算法/系统 | 年份 | 核心思想 | 迁移价值 | 备注 |
|-----------|------|---------|---------|------|
| **UniAD** | 2023 | 统一感知-预测-规划端到端 | ⭐⭐ 架构思想 | [GitHub](https://github.com/opendrivelab/uniad), CVPR最佳论文 |
| **GenAD** | 2024 | 生成式端到端驾驶 | ⭐⭐ 思路 | [ECCV](https://dl.acm.org/doi/10.1007/978-3-031-73650-6_6), 314次引用 |
| **PPAD** | 2024 | 迭代预测-规划交互 | ⭐⭐⭐ 可迁移 | [ECCV](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/05165.pdf), 53次引用 |
| **Occupancy Prediction** | 2024-25 | 3D占据预测辅助规划 | ⭐⭐⭐ 直接相关 | 你的体素地图本质就是occupancy |

**迁移价值：** 自动驾驶的"occupancy prediction → planning"管线和你的"体素地图 → 视点规划"在结构上同构。PPAD的"迭代预测-规划交互"思想可以迁移为"预测赋色增益 → 规划路径 → 更新预测 → 重规划"的闭环。

## 推荐算法组合

### 短期（2个月比赛）

```
┌─────────────────────────────────────────────────┐
│  SLAM层: FAST-LIO2 (ROS2) + OctoMap             │
│  ↓ 3D体素地图                                    │
│  探索层: Station-Viewpoint Joint CPP             │
│         + PB-NBV 投影可见性计算                   │
│         + 信息增益评分 (OctoMap熵变)              │
│  ↓ 目标视点 (x, y, yaw)                          │
│  规划层: A* (2D栅格) + 朝向约束                   │
│  ↓ 路径                                          │
│  控制层: Pure Pursuit + 点云局部避障              │
│  ↓ cmd_vel                                       │
│  驱动层: Unitree SDK2                            │
└─────────────────────────────────────────────────┘
```

**核心参考：**
- Becoy 2025 (Go2覆盖路径规划) — 整体框架
- PB-NBV 2025 — 可见性计算
- Station-Viewpoint Joint CPP 2025 — 站点+视点联合优化
- frontier_exploration_ros2 — 工程起点

### 长期演进

```
Phase 2 (赛后): + RL探索策略 (MA-SLAM思路)
Phase 3:        + LiteVLA-Edge 做高层语义决策
Phase 4:        + VLM引导探索 (Berkeley 2025)
Phase 5:        + LOVON 语义层集成 (自然语言任务调度)
```

## LOVON 在整个体系中的定位

```
┌────────────────────────────────────────────────────┐
│            长期完整系统                               │
├────────────────────────────────────────────────────┤
│  Layer 4: 语义理解 (LOVON IOE + VLM)               │  ← LOVON
│           "去扫描左边的红色柜子"                      │
├────────────────────────────────────────────────────┤
│  Layer 3: 任务规划 (LLM/VLA)                        │  ← LiteVLA-Edge
│           分解为子目标序列                            │
├────────────────────────────────────────────────────┤
│  Layer 2: 探索/覆盖规划 (NBV + CPP)                │  ← 比赛核心
│           选择下一个最优视点                          │
├────────────────────────────────────────────────────┤
│  Layer 1: 运动规划+控制 (A* + Pure Pursuit + SDK2)  │  ← 基础设施
│           安全到达目标位置                            │
├────────────────────────────────────────────────────┤
│  Layer 0: 感知 (FAST-LIO2 + 相机 + OctoMap)         │  ← 基础设施
│           3D体素地图 + 赋色状态                       │
└────────────────────────────────────────────────────┘
```

LOVON 在 Layer 4（语义理解层），比赛时可选不上场（没有语言指令输入），但长期是系统的"大脑"。比赛核心在 Layer 2（探索/覆盖规划）。
